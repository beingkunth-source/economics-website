# 🌐 Economics Website

A simple static website designed to present economics-related content in a structured and easy-to-understand format.  
This project focuses on clean layout, basic web development concepts, and fast deployment.

---

## 🚀 Live Demo  
🔗 [Visit Website](https://economics-website.vercel.app/index.html)

---

## 📌 Features  

- 📚 Structured economics content  
- 🎨 Simple and clean UI  
- ⚡ Fast loading static pages  
- 🔗 Easy navigation between sections  
- ☁️ Deployed using Vercel  

---

## 🛠️ Tech Stack  

- HTML  
- CSS  
- JavaScript (if used)  
- Vercel (Deployment)

## ▶️ How to Run Locally  

1. Clone the repository  
```bash
git clone https://github.com/your-username/economics-website.git
```

2. Open the folder  

3. Run by opening:  
```
index.html
```
